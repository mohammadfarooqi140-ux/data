How to make it yours
This page is the complete source code in one file, the same one that runs the demo above. Save this page (browser menu → Save page, or long-press the link you received) and open the file in any browser, it runs as is. Change the colours in the <style> block, wire the 4-digit check to your own /api/otp/verify endpoint in the <script> block, and it is your verification screen.
